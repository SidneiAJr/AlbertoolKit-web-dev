# 🛠️ Albertool-DevKit

## Ecossistema de automação para desenvolvedores

*"Preguiça? Chama de eficiência."*

---

## 📌 Sobre

**Albertool-DevKit** é um ecossistema de ferramentas criado para automatizar tarefas repetitivas do dia a dia de um desenvolvedor.

Cansado de criar a mesma estrutura de pastas toda vez?  
Cansado de ficar copiando dependência de projeto em projeto?  
Cansado de sofrer com configuração inicial?

Aqui você encontra **esqueletos prontos**, **arquivos de dependência** e **estruturas organizadas** para começar seu projeto rapidamente.

## 🚀 Como usar

| Se você quer... | Use... |
|-----------------|--------|

### 2. Clone o repositório desejado
```bash
git clone https://github.com/SidneiAJr/NoMorePomPain.git
```

# 📁 Estrutura do Albertool-DevKit

## NoMorePomPain

**O que é:** 30+ arquivos de dependência prontos para copiar e colar.
```bash
NoMorePomPain/
├── Java-Poms/ # 6 arquivos pom.xml (do simples ao enterprise)
├── PHP-Composer/ # 6 arquivos composer.json
├── Node-JS/ # 6 arquivos package.json (JavaScript)
├── Node-TS/ # 6 arquivos package.json (TypeScript)
└── Python/ # 6 arquivos requirements.txt
```

```bash
Constellation-Backend-Only/
├── MVC/ # Model-View-Controller (JS, TS, PHP, Java)
├── ADR/ # Action-Domain-Responder (JS, TS, PHP, Java)
├── DDD/ # Domain-Driven Design (JS, TS, PHP, Java)
├── Hexagonal/ # Ports & Adapters (JS, TS, PHP, Java)
├── Clean/ # Clean Architecture (JS, TS, PHP, Java)
├── Layered/ # N-Tier tradicional (JS, TS, PHP, Java)
└── CQRS/ # Command Query Responsibility (JS, TS, PHP, Java)
```

```bash
Esqueletos_backend_enteprise/
├── backend-java/ # Spring Boot MVC (pom.xml + src/)
├── backend-nodejs/ # Express MVC (JavaScript)
├── backend-typescript/ # Express + TS MVC
```

```bash
Nosso-Frontend/
├── css/
│ ├── simples/ # 3 arquivos (reset.css, style.css, responsive.css)
│ ├── hard/ # 15 arquivos organizados por responsabilidade
│ └── enterprise/ # 70+ arquivos (ITCSS, componentes, páginas, temas)
└── js/
├── simples/ # 2 arquivos (main.js, utils.js)
├── hard/ # 11 arquivos (core, modules, components, services)
└── enterprise/ # 70+ arquivos (core, hooks, stores, middleware)
```
