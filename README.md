# 🛠️ Albertool DevKit

*"Lazy? Call it efficiency."*

---

## Why does this exist?

I got tired of Googling the same install commands over and over.  
`npm i express cors mysql typeorm` — sure, I know that one.  
But what about the full enterprise stack with auth, cache, queues and tests?  
Yeah. Nobody memorizes that.

So I built this. For me. And now for you too.

---

## What's inside?

Everything I study, use and build — organized so you can grab what you need and start coding:

- 📄 **Markdowns** with ready-to-run install commands by language and level
- 🏗️ **Project skeletons** for the main architectural patterns
- 🔌 **Frontend → Backend integration templates**
- 🖥️ **Bash scripts** that scaffold a full project structure in one command
- 🐳 **Docker** setups ready to go
- 🧩 **UI components** for React, Angular, React Native, Flutter and HTML

---

## Levels

Every language follows the same progression:

| Level | What it adds |
|-------|-------------|
| `simples` | Bare minimum to run something |
| `básico` | Core dependencies to start a real project |
| `intermediário` | Auth, validation, database |
| `avançado` | Cache, queues, tests |
| `complexo` | Robust architecture with monitoring |
| `enterprise` | Full production stack |
