# Comandos para Instalar | React Native

## Iniciando Projeto
```bash
npx create-expo-app meu-app
cd meu-app
```

## Simples
```bash
npx expo start
```
> Só o Expo padrão, sem dependências extras

---

## Simples
```bash
npm i axios
npm i -D typescript @types/react @types/react-native
```

## Básico
```bash
npm i axios dotenv zustand react-hook-form zod @hookform/resolvers
npm i -D typescript @types/react @types/react-native
```
