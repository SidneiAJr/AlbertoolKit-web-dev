# Comandos para Instalar | TypeScript

## Backend | MySQL Puro

### Simples
```bash
npm i express mysql2
npm i -D typescript @types/express @types/node ts-node
```

### Básico
```bash
npm i express cors mysql2 dotenv
npm i -D typescript @types/express @types/cors @types/node ts-node
```

### Intermediário
```bash
npm i express cors mysql2 dotenv bcrypt
npm i -D typescript @types/express @types/cors @types/node @types/bcrypt ts-node
```

### Avançado
```bash
npm i express cors mysql2 dotenv bcrypt jsonwebtoken zod
npm i -D typescript @types/express @types/cors @types/node @types/bcrypt @types/jsonwebtoken ts-node
```

### Complexo
```bash
npm i express cors mysql2 dotenv bcrypt jsonwebtoken zod redis
npm i -D typescript @types/express @types/cors @types/node @types/bcrypt @types/jsonwebtoken ts-node jest @types/jest ts-jest
```

### Enterprise
```bash
npm i express cors mysql2 dotenv bcrypt jsonwebtoken zod redis bull axios winston
npm i -D typescript @types/express @types/cors @types/node @types/bcrypt @types/jsonwebtoken ts-node jest @types/jest ts-jest eslint prettier husky lint-staged
```
