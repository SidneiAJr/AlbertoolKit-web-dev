# 📦 Arquivos de Dependência Prontos

> ## ⚠️ VERIFIQUE AS VERSÕES ANTES DE USAR
>
> As dependências deste repositório podem estar desatualizadas.  
> Sempre verifique e atualize as versões após copiar qualquer arquivo.
>
> **Após instalar, rode:**
>
> ```bash
> # Node.js / React / React Native
> npm outdated
>
> # Atualizar tudo de uma vez
> npx npm-check-updates -u && npm install
> ```
>
> ⚠️ `npm outdated` mostra o que tá velho  
> ⚠️ `npx npm-check-updates -u` atualiza o `package.json` automaticamente  
> ✅ Depois é só rodar `npm install` e testar
