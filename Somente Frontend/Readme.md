## 🧩 Componentes disponíveis

Os componentes abaixo estão disponíveis para **Angular** e **React Web**, com versões com e sem CSS:

| Componente | Descrição |
|------------|-----------|
| `accordion` | Seções expansíveis de conteúdo |
| `avatar` | Exibição de foto/iniciais de usuário |
| `badge` | Indicadores e etiquetas de status |
| `breadcrumb` | Navegação hierárquica |
| `button` | Botões com variações de estilo |
| `card` | Container de conteúdo em cartão |
| `checkbox` | Caixas de seleção customizadas |
| `date-picker` | Seletor de data |
| `dropdown` | Menu suspenso de opções |
| `input` | Campos de entrada de texto |
| `modal` | Janelas modais e diálogos |
| `pagination` | Navegação entre páginas |
| `progress-bar` | Barra de progresso linear |
| `progress-circle` | Progresso em formato circular |
| `rating-stars` | Avaliação por estrelas |
| `select` | Seletor de opções estilizado |
| `skeleton` | Placeholder de carregamento |
| `spinner` | Indicador de loading |
| `switch` | Toggle on/off |
| `table` | Tabela de dados |
| `tabs` | Navegação por abas |
| `toast` | Notificações temporárias |
| `tooltip` | Dicas ao passar o mouse |

## 🚀 Como usar

1. Navegue até a pasta da plataforma que você usa
2. Escolha o componente que precisa
3. Copie pra dentro do seu projeto
4. Ajuste o estilo se quiser — a estrutura já tá pronta
